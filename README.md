# ربات تلگرام رایگان با Cloudflare Workers AI (نسخه‌ی مخصوص گوشی — بدون نیاز به CLI)

این پروژه یک ربات تلگرام است که کاملاً **رایگان** روی Cloudflare اجرا می‌شود،
**مکالمه رو یادش می‌مونه**، و همه‌ی مراحل ساخت و دیپلوی فقط با **مرورگر گوشی** انجام می‌شه —
نیازی به نصب هیچ برنامه یا استفاده از خط فرمان (wrangler) نیست.

---

## مرحله ۱: ساخت ربات در تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده.
2. دستور `/newbot` را بفرست و اسم و یوزرنیم دلخواه را وارد کن.
3. یک توکن شبیه `123456789:AAExxxxx...` می‌گیری — جایی ذخیره‌اش کن.

## مرحله ۲: بالا بردن کد در گیت‌هاب (با مرورگر)

1. وارد github.com شو و یک ریپازیتوری جدید بساز (public یا private، فرقی نمی‌کنه).
2. داخل ریپازیتوری روی **Add file → Create new file** بزن.
3. برای هر فایل این کار رو تکرار کن:
   - `src/index.js` → محتوایش رو از فایلی که برات فرستادم کپی/پیست کن (وقتی مسیر `src/index.js` رو تایپ کنی، گیت‌هاب خودش پوشه‌ی `src` رو می‌سازه)
   - `wrangler.toml`
   - `package.json`
4. هر بار روی **Commit new file** بزن.

(این کار کاملاً با مرورگر گوشی هم قابل انجامه، نیازی به اپ یا کامپیوتر نیست.)

## مرحله ۳: ساخت KV Namespace برای حافظه‌ی مکالمه

1. وارد داشبورد Cloudflare شو: dash.cloudflare.com
2. از منو برو به **Workers & Pages → KV**
3. روی **Create a namespace** بزن، اسمش رو مثلاً `CHAT_HISTORY` بذار.
4. بعد از ساخت، یک **Namespace ID** می‌بینی — اون رو کپی کن.
5. برگرد به گیت‌هاب، فایل `wrangler.toml` رو باز کن، روی آیکون مداد (Edit) بزن، و جای
   `PUT_YOUR_KV_NAMESPACE_ID_HERE` مقدار واقعی رو جایگزین کن، بعد Commit.

## مرحله ۴: وصل کردن گیت‌هاب به Cloudflare Workers (دیپلوی خودکار)

1. در داشبورد Cloudflare برو به **Workers & Pages → Create → Workers → Connect to Git**
2. اجازه بده Cloudflare به اکانت گیت‌هابت وصل بشه و ریپازیتوری‌ای که ساختی رو انتخاب کن.
3. Cloudflare خودش پروژه رو می‌شناسه و دیپلوی می‌کنه. از این به بعد هر تغییری در گیت‌هاب بدی،
   خودکار دوباره دیپلوی می‌شه.
4. بعد از دیپلوی اول، به تنظیمات ورکر برو (**Settings → Bindings**) و مطمئن شو
   binding مربوط به **AI** و **CHAT_HISTORY (KV)** درست وصل شده‌اند؛ اگر نبودند، همون‌جا
   با دکمه‌ی **Add binding** دستی اضافه‌شون کن (این‌ها معمولاً از روی `wrangler.toml` خودکار تشخیص داده می‌شن).

## مرحله ۵: تنظیم Secret ها (بدون CLI)

1. همچنان در همون ورکر، برو به **Settings → Variables and Secrets**
2. روی **Add variable** بزن:
   - Name: `TELEGRAM_BOT_TOKEN` — Value: همون توکنی که از BotFather گرفتی — گزینه‌ی **Encrypt** رو فعال کن
3. دوباره **Add variable** بزن:
   - Name: `WEBHOOK_SECRET` — Value: هر رشته‌ی دلخواه و تصادفی (مثلاً یه پسورد قوی که خودت بسازی) — این رو هم Encrypt کن
4. ذخیره کن؛ ورکر خودکار با تنظیمات جدید redeploy می‌شه.

## مرحله ۶: وصل کردن Webhook تلگرام

آدرس ورکرت یه چیزی شبیه این می‌شه:
`https://telegram-ai-bot.<your-subdomain>.workers.dev`

فقط کافیه این آدرس رو (با مقادیر واقعی خودت به‌جای `< >`) در مرورگر گوشیت باز کنی:

```
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://telegram-ai-bot.<your-subdomain>.workers.dev&secret_token=<WEBHOOK_SECRET>
```

اگه جواب `{"ok":true,...}` گرفتی، وصل شد.

## مرحله ۷: تست

به ربات تلگرامت پیام بده. حالا:
- مکالمه رو یادش می‌مونه (تا ۱۰ پیام آخر، و بعد از ۳ روز بی‌استفاده‌بودن خودکار پاک می‌شه)
- با دستور `/reset` می‌تونی حافظه‌ش رو دستی پاک کنی و از اول شروع کنی

---

## همه‌چیز از گوشی، بدون CLI

خلاصه‌ی کارهایی که فقط با مرورگر انجام دادی:
- ✅ گیت‌هاب: ساخت فایل‌ها از طریق وب
- ✅ Cloudflare: ساخت KV namespace از داشبورد
- ✅ Cloudflare: اتصال گیت‌هاب و دیپلوی خودکار از داشبورد
- ✅ Cloudflare: تنظیم Secret ها از داشبورد
- ✅ وصل‌کردن webhook: فقط باز کردن یک لینک در مرورگر

هیچ‌جا نیازی به نصب wrangler یا استفاده از ترمینال نبود.
